How to Use This Email Signature

Gmail:

  1. Open the HTML file in your web browser
  2. Select and copy the signature table (between the START and END markers)
  3. Go to Gmail Settings → See all settings → General → Signature
  4. Paste the signature
  5. Update the social media links to your actual profiles
  6. Scroll down and click "Save Changes"

Outlook (Desktop):

  1. File → Options → Mail → Signatures
  2. Click "New" to create a new signature
  3. Open this HTML file in a browser, copy the signature table
  4. Paste it into the signature editor
  5. Update the social media links

Apple Mail:

  1. Mail → Settings → Signatures
  2. Click "+" to create a new signature
  3. Open this HTML file in a browser, copy the signature table
  4. Paste it into the signature field
  5. Update the social media links
